# class-diagram# 
Student Class Design

## Description

This project demonstrates how a student class design can be implemented
using Python object-oriented programming.

## Classes

### Student
Stores student information and manages course enrollments.

### Course
Stores course information.

### Enrollment
Connects students with courses and stores grades.

## Technologies

- Python
- Object-Oriented Programming

## How to Run

Run the following command:

python student_management.py
